AeroTrack Race Day Guide

Everything you need to set up and run your AeroTrack devices — tap any step to open it.

The night before

One thing to do before you leave the house.

1

Charge every device to 100%

So nothing shows up half-charged on race morning.

Charge every AeroTrack fully the night before, using its USB-C port. Use the cable that shipped with the device, or any cable and power source rated at 2 amps or greater.

Good to know: A cable or power source under 2 amps may not fully charge the device, or keep it charged while it's reading tags. If you're using a replacement cable, make sure it's 2 amps or higher.

When you arrive at the venue

Power on, place the devices, and run through a few quick checks.

2

Power on — no earlier than 1 hour before

Turning them on too early just wastes battery.

Once you're on site, power on each AeroTrack no more than an hour before the event begins. AeroTrack batteries can drain faster than expected if a device sits on for a long stretch before it's actually needed — waiting keeps every device as fresh as possible for the race.

3

Open the app & check the time

One glance at the Dashboard tells you if it's right.

Find and open the MobileTrack app icon on the home screen — that's the app on every AeroTrack device, and it opens straight to the Dashboard.

Right under the ChronoTrack logo, the Dashboard shows App Date & Time with the current source in parentheses (like "Phone" or "NTP") and a live clock. That's your at-a-glance time check.

AeroTrack devices are normally left set to NTP (network time), pulled over cellular or Wi-Fi — so once a device is online, every device set to NTP should show the same, correct time automatically.

Goal: All devices show the same, correct time. If that's what you see, you're done here.
Time looks wrong? Fix it here

If a device's time doesn't look right, or doesn't match the others:

  1. Tap the menu icon (☰) in the top-left corner of the Dashboard.
  2. Choose Set Time.
  1. Tap the Set time using dropdown.
  2. Choose NTP to pull correct time from the network. This is the standard setting.
  1. Confirm Use Phone Timezone is on and the timezone is correct for the event location.
  2. Tap Set App Time.

Need several devices to match exactly and they're on the same Wi-Fi? Set the time on one, then use Broadcast Time at the bottom of this screen to push it to the others.

4

Confirm the event & location name

Just a check — these are already set up for you.

Each device's Event and Point (location) name is preconfigured ahead of time, so you shouldn't need to change anything. This step is just a confirmation.

The Dashboard shows both right at the top, under Event Name and Point Name — no need to open another screen.

If either name looks off: stop and check in before making a change.

Since this guide gets reused for future events: every event morning, confirm the name on each device before you rely on it — a quick check protects against a name left over from a previous race.

Name needs to be changed?
  1. Tap the menu icon (☰) in the top-left corner.
  2. Choose Set Event & Point.
  3. Tap the Event or Point field and enter the correct name.
  4. Tap Set Event & Point to save. It confirms with Event & Point Set.

5

Position the device

Handheld or mounted — pick the setup that matches your spot.

The AeroTrack can be run two ways: handheld by an operator, or mounted stand-alone on the side of the course. Handheld produces better read rates; mounted can be left to run without someone operating it.

Handheld

Aim the device directly at the bib or tag you're trying to read, and make sure no spectators or event staff are standing in front of you.

Read range: The ideal read range is about 10 feet, but the AeroTrack can read closer or considerably farther than that. Test your specific setup ahead of time.

Each device's read strength fades the farther a tag is from the antenna — strongest directly in front, weakest at the outer edge of the pattern shown here:

Mounted (stand-alone)

A mounted AeroTrack can read tags without an operator, but shouldn't be left completely unattended — keep an eye out for theft or anyone standing in front of it. Mount the device roughly 4 feet off the ground, angled slightly inward toward the timing point rather than straight across the course.

Course width determines whether you need a single device or a pair, positioned 10 feet (3 meters) back from the timing point on each side:

  • Single — course width up to 3 meters (3× 42″ Gators US, or 3× 36″ Gators INT).
  • Paired (one AeroTrack each side) — course width up to 5 meters (4× 42″ Gators US, or 5× 36″ Gators INT).

Right before the race starts

Keep readers off until go-time, then switch them all on together.

6

Keep the reader OFF until start

Don't let a device sit there reading before it's needed.

The trigger starts and stops continuous tag reading. Pull and release it once to toggle on or off — you don't need to hold it down.

After you've checked the app, the time, and the event name, make sure the reader is not actively reading yet. A device left scanning while it's just sitting there burns battery faster and logs data you don't need.

Look at the gun-shaped status icon next to the ChronoTrack logo at the top of the Dashboard:

Red = reader off (idle). Green = reader on (reading). You can also check Recent Reads → Total — it stays at 0 while idle.
Before race start: confirm every device's icon is red. If one shows green, pull the trigger once to turn it off.

7

Turn every reader ON at race start

Pull the trigger on each device just before athletes go.

Just before the race starts, pull and release the trigger once on each AeroTrack to begin continuous reading. The status icon switches from red to green, confirming the reader is active.

Confirm before athletes arrive: every device's icon should show green. If one's still red, pull the trigger once more.

During the race

Two quick checks, every time you pass a device.

8

Watch the reader & cloud icons

Two icons at the top of the Dashboard tell you if it's working.

Two status icons sit next to each other at the top of the Dashboard, next to the ChronoTrack logo:

  • Trigger icon — red means the reader is off, green means it's actively reading.
  • Cloud icon — a green cloud with a checkmark means the device's data is streaming successfully to the server and back to the timer.
What you want to see: trigger icon green (reading) and cloud icon green with a checkmark (syncing).
Cloud icon not green? The device isn't sending its data. Reach out to the timer right away.

9

Check battery periodically

AeroTracks can drain quickly if left unchecked.

AeroTrack batteries can run down faster than you'd expect while a device is actively reading, so check on your devices periodically rather than assuming they're fine.

Below 20% battery: don't trust the reported percentage — reading performance can get inconsistent. Get external power on the device as soon as possible.

If a device is running low, connect an external battery bank to its USB-C port. The AeroTrack stays fully functional — reading tags and running the app — while it charges.

Tip: Where possible, top off with an external battery bank.

If something's wrong

Quick fixes for the one thing that tends to go sideways.

!

Emergency: connect to a different network

Use this if cellular isn't working on a device.

If a device can't get a cellular connection, connect it to Wi-Fi instead using the standard Android Wi-Fi setup:

  1. From the home screen, swipe upward to open the app drawer.
  2. Choose Settings.
  3. Choose Network & internet.
  4. Select the Wi-Fi network you want to connect to from the list.
  5. Enter the password, if required, and connect.
After connecting: check the cloud icon on the Dashboard (Step 8) to confirm the device is syncing again.
